# Encircle dictionary

`wiktionary-words.json` is generated by `pnpm dictionary:update` from the English entries in the
[Kaikki Simple English Wiktionary extraction](https://kaikki.org/dictionary/rawdata.html). The build
includes lowercase alphabetic headwords and inflected forms while excluding proper names, phrases,
affixes, symbols, and punctuation.

The extracted data is available under the same CC BY-SA and GFDL licenses as Wiktionary. Kaikki's
Wiktextract project converts the source dump to machine-readable JSONL.
